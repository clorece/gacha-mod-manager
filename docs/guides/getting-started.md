# Getting started

From an empty Mods folder to your first mod in game, in five steps.

## 1. Set up XXMI Launcher

GMM manages mods; **XXMI Launcher** loads them into the game. If a game on the Dashboard shows
**Needs setup** or **XXMI not found**, open its setup card: the setup guide walks you through
installing XXMI, ticking the game under "Select Games To Mod:", pressing "Install", and
saying yes to XXMI's prompts. Press **Check again** when you're done. See
[Fixing setup problems](fixing-setup.md) if a game stays stuck.

## 2. Find a mod

Open the **Mods Store**. Pick a game in **Select Game** (or keep All games), then search, or
filter by category and character. Click a card to open the mod's page: pictures,
description, files, updates, credits and the author's license.

## 3. Install it

Press **Download**. GMM fetches the file, checks it, and shows what it will install before
anything happens: which file, which versions if the archive holds several, and anything it
refused to install. Confirm, and the install runs on the **Downloads** page.

## 4. Switch it on or off

The **Mods Library** lists everything in your Mods folders, including mods you added by
hand. Each card has a switch. Off means XXMI skips the mod the next time the game starts; your
in-game toggles for it are kept for when it comes back on.

## 5. Play

Back on the **Dashboard**, open the game's banner and press **Launch**. Mods only load when the
game starts through XXMI, so always start it from GMM (or from XXMI itself).

## Where to change things later

**Settings** holds the theme, whether sensitive mods are shown, the XXMI folder, your game
folders and the caches. Every mod has its own **Mod settings** (the round button on its card):
versions, updates, key bindings, the folder and Uninstall.
