# GMM guides

Short guides for players. The app's **Documentation** page is built from these files when
GMM is built, so what you read here is what the app shows (installed copies don't fetch
anything). Edit a guide here and the next build of the app carries the change.

Each guide starts with a `# Title` and a one-line summary paragraph: the Documentation page
uses them for its cards. Links to another guide (`conflicts.md`) open it inside the app;
other links show as plain text there.

4. [Installing safely](installing-safely.md)
