Gacha Mod Manager adds **Arknights: Endfield**, next to **Zenless Zone Zero** and **Wuthering
Waves**, on Windows.

> [!IMPORTANT]
> **The installer isn't code-signed yet.** Coming from 0.0.2 beta, GMM updates itself: just
> start it. Installing by hand? Right-click the `.msi` → **Properties** → tick **Unblock** at
> the bottom of the General tab → **OK**. More help in the
> [install steps](https://github.com/clorece/gacha-mod-manager#install-on-windows).

## New: Arknights: Endfield

- Browse, install and switch Endfield mods from GameBanana, and launch the game with them
  through XXMI (its **EFMI** mod loader).
- GMM finds the game on **Steam**. It also looks in **Epic** and Gryphline's own launcher
  (**GRYPHLINK**), but those haven't been tried on a real install yet: if GMM misses your
  game, add its folder in **Settings › Games** (and please
  [tell us](https://github.com/clorece/gacha-mod-manager/issues)).
- The Mods Store sorts skins by operator: pick **Operators**, then one or more operators.
  Weapons, UI and Other/Misc have their own categories.
- Set up XXMI for Endfield the same way as for the other games: tick it under "Select Games To
  Mod:" in XXMI Launcher and press **Install**. GMM's setup check tells you if anything is
  missing. The Steam copy works with XXMI's "Game Launch" on **Steam** or **Direct**; the
  GRYPHLINK copy needs **Direct**.

## Changed

- Endfield has its own banner on the Dashboard and in the game picker.
- The setup guides name EFMI, and Privacy lists GRYPHLINK among the places GMM looks for games.

## You need

- Windows 10 or 11, 64-bit.
- [XXMI Launcher](https://github.com/SpectrumQT/XXMI-Launcher/releases), set up for your game.

## Files

- `GMM-0.0.3-beta-x64.msi`: the installer.
- `SHA256SUMS.txt`: its checksum.
- `GMM-0.0.3-beta-x64.msi.sig`: its signature, for GMM's updater.
