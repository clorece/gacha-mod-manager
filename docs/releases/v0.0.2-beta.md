Bug fixes and tweaks for Gacha Mod Manager, for **Zenless Zone Zero** and **Wuthering Waves**
on Windows.

> [!IMPORTANT]
> **The installer isn't code-signed yet.** Before opening it, right-click the `.msi` →
> **Properties** → tick **Unblock** at the bottom of the General tab → **OK**. More help in the
> [install steps](https://github.com/clorece/gacha-mod-manager#install-on-windows).

## New: GMM updates itself

When GMM starts and finds a newer version, it downloads it with a progress bar, checks that the
installer is signed by GMM, and installs it. Windows may ask you to allow it, then GMM reopens
by itself. Settings › About has **Update now** too.

This starts with this version: coming from 0.0.1 beta, install this one by hand.

## Fixed

- Mods with large, mostly blank textures (like FX masks) no longer fail to install with
  "possible zip bomb". Real zip bombs are still refused.

## Changed

- Mod cards show when a mod was last updated: on the Mods Store, how long ago GameBanana last
  updated it; in the Library, when the creator uploaded the file you have installed.
- Mods Store cards read title, author, last update, then stats, with no gap under one-line
  titles.
- Report a Bug is one form: write your report, and the newest log file is chosen to attach
  (Change… picks another from the log folder). After the issue opens in your browser, GMM shows
  the log folder so you can drag the file in.

## You need

- Windows 10 or 11, 64-bit.
- [XXMI Launcher](https://github.com/SpectrumQT/XXMI-Launcher/releases), set up for your game.

## Files

- `GMM-0.0.2-beta-x64.msi`: the installer.
- `SHA256SUMS.txt`: its checksum.
- `GMM-0.0.2-beta-x64.msi.sig`: its signature, for GMM's updater.
