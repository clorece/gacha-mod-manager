The first public test release of Gacha Mod Manager, for **Zenless Zone Zero** and
**Wuthering Waves** on Windows.

> [!WARNING]
> **This installer is not code-signed.** Windows will warn about it, and on PCs where Smart
> App Control is on it is blocked outright. The README's
> [Windows install steps](https://github.com/clorece/gacha-mod-manager#windows) explain both
> and how to check the download's SHA-256 first. Signed builds come with a later release.

## What's in it

- **Mods Store**: browse and search GameBanana, with filters by category and character, and a
  mod page with previews, description, files, updates, credits and license.
- **Safe installs**: every download is checked before anything reaches XXMI's Mods folder
  (archive hardening, a policy scan, GameBanana's own virus scan result). Zip, 7z and RAR.
- **Mods Library**: switch mods on and off (your in-game toggles are kept), versions,
  updates and roll back, key bindings, profiles, conflicts, adopting hand-installed mods,
  installing from a local archive, uninstall.
- **Dashboard**: launch a game with mods through XXMI, setup checks with step-by-step fixes.
- **Storage**: what each mod and GMM's caches use, with clean-up.
- **Report a Bug**: a pre-filled GitHub issue you check and submit yourself. GMM sends no data
  of its own.

## Before you install

- Windows 10 or 11, 64-bit.
- [XXMI Launcher](https://github.com/SpectrumQT/XXMI-Launcher/releases), set up for your game.
  GMM manages mods; XXMI loads them.
- This is a beta. Mods you install with GMM go into `Mods/GMM/` in XXMI's folder, so they're
  easy to find (and remove by hand) if something goes wrong.

## Files

- `GMM-0.0.1-beta-x64.msi`: the installer.
- `SHA256SUMS.txt`: its SHA-256 checksum.
