The first test release of Gacha Mod Manager, for **Zenless Zone Zero** and **Wuthering
Waves** on Windows.

> [!IMPORTANT]
> **The installer isn't code-signed yet.** Before opening it, right-click the `.msi` →
> **Properties** → tick **Unblock** at the bottom of the General tab → **OK**. More help in the
> [install steps](https://github.com/clorece/gacha-mod-manager#install-on-windows).

## What it does

- Browse and search GameBanana mods, with previews, files and updates.
- Checks every download before it reaches XXMI's Mods folder. Zip, 7z and RAR.
- Switch mods on and off (in-game toggles kept), versions, update and roll back, profiles,
  conflicts, adopting hand-installed mods, installing from a file.
- Launch the game with mods through XXMI.
- Report a Bug opens a pre-filled GitHub issue; GMM sends no data itself.

## You need

- Windows 10 or 11, 64-bit.
- [XXMI Launcher](https://github.com/SpectrumQT/XXMI-Launcher/releases), set up for your game.

GMM installs its mods into `Mods/GMM/` inside XXMI's folder, so they're easy to find or remove
by hand.

## Files

- `GMM-0.0.1-beta-x64.msi`: the installer.
- `SHA256SUMS.txt`: its checksum.
